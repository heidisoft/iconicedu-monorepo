# Activity Feed Variants

This reference lists the activity event variants we currently create and how
they render into feed items.

Canonical rendering is owned by
`apps/api/src/lib/activity-feed/definitions/activity-definitions.ts`. Web and
mobile should consume API-projected feed items rather than maintaining local
activity definition mirrors.

## Shared Render Rules

| Field                       | Rule                                                                                                                                                       |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `secondary` / context label | Prefer the per-recipient role-aware class label from `activityContext`; otherwise use `learningSpaceTitle`, `channelTopic`, or `title`.                    |
| Guardian context            | `{classTitle} for {viewerStudentNames or studentNames} with {teacherNames}`.                                                                               |
| Educator context            | `{classTitle} with {studentNames}`.                                                                                                                        |
| Child context               | `{classTitle} with {teacherNames}`.                                                                                                                        |
| Admin/staff context         | `{classTitle}: {students}, parents {guardians}, teacher {teachers}`.                                                                                       |
| Source href                 | Explicit `payload.href`; otherwise `/{orgSlug}/dm/{channelId}`, `/{orgSlug}/c/{channelId}`, or `/{orgSlug}/s/{channelId}` based on route kind/class scope. |
| Feed preview                | `summary` renders as the preview card. `expandedContent` renders behind read-more behavior.                                                                |
| Icons                       | Feed rows use `content.leading.iconKey` when present, then fall back from `verb`. Web and mobile map icon keys to Lucide icons.                            |

## Source Creation Matrix

| Source                     | Created activity event(s)                                                                                                                                                                                 | Dedupe                                                                                                                                    |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Message insert source job  | `message.posted` for channel/class messages and DMs; `message.mentioned` for mentions; `message.thread_reply.posted` for thread replies; `file.uploaded`, `image.uploaded`, or `audio.uploaded` for files | `{eventType}:{messageId}`, `message.mention:{messageId}:{recipientProfileId}`, or `message.thread-reply:{messageId}:{recipientProfileId}` |
| Reaction insert source job | `reaction.added`                                                                                                                                                                                          | No explicit event dedupe key; source job is `reaction:{reactionId}`                                                                       |
